# 玩机装机工具 · 产品规划 v0.1

> 定位：Windows 游戏运行环境一键检测与安装工具。**只装官方源、每步可验证、轻到双击即跑。**
> 技术：Flutter Desktop（自带渲染器，用户零依赖）→ 单文件 exe ~35MB。

## 一、为什么做这个（差异化）

| 现状 | 问题 | 我们 |
|---|---|---|
| DirectX Repair | 年久失修、闭源、捆绑历史 | 只用官方安装包、开源可查、每步写日志 |
| 各类"运行库合集" | 来路不明的打包，杀软常报 | 不打包任何第三方安装器——现下现装，链接可点 |
| 手动装 | 玩家根本不知道缺什么 | 检测→报告→一键装齐→验证 |

**杀手功能（v0.2）**：「按游戏检查」——选《星露谷》只扫它要的组件。数据来自网站 `data/games`，工具与站点互通。

## 二、用户侧硬指标（设计约束）

- **零依赖**：任何 Win10/11（x64）双击即跑，不需要 WebView2/不需要 .NET 新运行时/不需要装任何东西
- **启动不弹 UAC**：扫描只读注册表，普通权限即可；**只在「一键装齐」时提示一次提权**（重进进程 runas，标准做法）
- **杀软友好**：不压缩壳/不混淆（UPX 是报毒主因）、单 exe、发布页附 SHA256 + VirusTotal 链接；后期可考虑代码签名证书
- **离线可用**：扫描/报告完全离线；仅「安装」时联网下载官方包；后期出离线整合包模式
- **可回滚可查**：每个动作写日志 `%APPDATA%\WanjiKit\logs\`，装了什么、从哪下的、退出码，全留痕

## 三、架构：数据驱动（可维护性核心）

```
catalog/runtimes.json   ← 组件目录：新增运行库 = 加一条 JSON，不写代码
engine/                 ← Dart 引擎
  ├─ catalog.dart       #   解析目录（内置 asset + 支持外挂 catalog.json 热更新）
  ├─ detect.dart        #   执行 detect 规则 → installed/missing/outdated
  ├─ install.dart       #   安装队列：winget 优先 → 官方直链兜底（SHA256）→ 重扫验证
  ├─ elevate.dart       #   管理员检测/自我 runas 重启
  └─ log.dart           #   JSONL 日志
lib/ui/                 ← Flutter 界面（自有视觉体系）
  ├─ screens/           #   boot / scan / result / install / done
  └─ widgets/           #   状态徽标、清单行、进度流、日志尾
```

**detect 规则类型**：`registry`（键值存在/等于/版本≥）、`file`（System32/SysWOW64 存在+版本）、`command`（如 `dotnet --list-runtimes` 含某行）、`winsxs`（旧 VC++ 在 WinSxS 探测）。

**install 策略**：`winget`（官方签名包、自带校验）→ `download`（微软官方直链 + 静默参数 + SHA256）→ 均失败时给手动链接。退出码语义化：0=成功，3010=成功需重启，1638=已装更新版，其他=失败+原始码。

## 四、界面（自有视觉体系，不抄网站）

基调：**「精密仪器」**——深色石墨底、衬线大标题（宋体）、mono 数据、发丝线、信号橙只给主按钮。和网站是同一品牌家族但不同脸：网站是「放映厅」，工具是「控制台」。

1. **Boot**：超大宋体标语 + 系统信息 mono 行（OS 版本/架构/已装组件概数）+ 唯一橙色 CTA「开始检测」
2. **Scan**：左栏大计数（n/N 已完成），右栏清单逐条扫描浮现 ✓已装 / ✗缺失 / !过旧，发丝进度线
3. **Result**：分组展示（缺失红/过旧黄/已装灰），每行：名称·当前→所需版本·「游戏需要它的原因」·来源域名；顶部汇总「缺 N 项 · 预计 X 分钟」+ CTA「一键装齐」
4. **Install**：逐项进度流，当前项放大，底部 mono 日志滚动尾；失败项标出原因+手动链接
5. **Done**：结果汇总 + 「重新检测」「打开日志」「完成」

侧栏框架预留：`检测` / `按游戏检查(v0.2)` / `离线包(v0.3)` / `设置`。

## 五、检测项清单 v1（catalog/runtimes.json）

VC++ 全家桶（2005→2022，x86+x64 都查——x64 系统跑 32 位游戏要 x86 包）、.NET Framework 4.8、.NET Desktop Runtime 8、DirectX June 2010 旧组件（D3DX9/X3DAudio/XAudio 系列）、XNA 4.0、PhysX、OpenAL。每项含 detect/install/verify/why/tags。

## 六、路线图

- **v0.1**：catalog + 扫描 + 报告 + winget/直链安装 + 提权 + 日志 + 单 exe
- **v0.2**：按游戏检查（网站数据）、修复/重装模式、catalog 服务器热更新
- **v0.3**：离线整合包、自动更新、CLI 模式（`wanji-kit scan --json`）、i18n
- **后期**：代码签名、企业静默部署参数

## 七、风险与对策

- **杀软误报**：不压缩壳+开源+VT 公示；观察期后再加签名
- **winget 不存在/老系统**：全链路有直链兜底，不依赖 winget 存活
- **检测误报**：规则保守——拿不准标「待核验」不标「缺失」；每条检测显示依据（注册表路径/文件路径）
- **安装失败**：不中断队列，单项目标失败+原因+手动链接，完成后重扫
